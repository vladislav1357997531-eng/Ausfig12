# Ausfig12 V5

Готовый пакет для GitHub Pages. Интерфейс сохранён, криптографическое ядро обновлено.

## Что изменено

- Новое шифрование создаёт контейнеры Ausfig12 V5.
- KDF: Argon2id, 64 MiB, 3 прохода, parallelism 4, 64-byte master key.
- Разделение ключей: HKDF-SHA-512 с отдельными ключами для SUB, SHUFFLE, MIX, AEAD и DECOY.
- Фирменная многослойность: keyed byte substitution -> keyed 64-byte block shuffle -> AES-256-CTR MIX.
- Финальная криптографическая оболочка: AES-256-GCM с полным заголовком контейнера как AAD.
- Случайные salt, id, nonce, mix counter и tweak для каждого сообщения.
- Bucket padding сохранён.
- CRC32 оставлен как быстрая проверка повреждения до запуска Argon2id.
- Decoy-ответ при неверном кодовом слове/PIN сохранён.
- Исправлена генерация больших случайных padding-блоков: getRandomValues вызывается безопасными чанками <= 65536 байт.
- Расшифровка старых контейнеров V4 сохранена. Новое шифрование всегда V5.
- Старое V4-шифрование и лишний двойной GCM/CTR каскад для новых сообщений удалены.

## Загрузка на GitHub Pages

Замените содержимое репозитория этими файлами:

- `index.html`
- `manifest.webmanifest`
- `icon.svg`
- `sw.js`

После публикации один раз обновите страницу. Service Worker использует новый cache id `ausfig12-v5-core-1`, поэтому старый V4 UI-кэш будет удалён.

## Argon2

Используется зафиксированная версия `argon2-browser 1.18.0` с cdnjs. В `index.html` задан SHA-512 Subresource Integrity hash; при подмене файла браузер не выполнит библиотеку. Service Worker пытается сохранить библиотеку в offline-cache после установки.

## Совместимость

- V5: шифрование + расшифровка.
- V4: только расшифровка для старых сообщений.
- Более старые/неизвестные версии отклоняются.

## Важно

Стойкость зависит прежде всего от кодового слова и PIN. Алгоритм можно считать публичным: знание исходного кода не должно заменять знание секрета.
